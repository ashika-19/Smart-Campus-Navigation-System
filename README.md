# Smart Campus Navigation System

## Project Overview

The Smart Campus Navigation System is an AI-based web application that helps students, faculty, and visitors navigate a college campus by finding the shortest and most efficient route between locations.

## Features

- Find shortest path between campus buildings
- Interactive campus map
- Alternative route suggestions
- Estimated travel time
- Accessibility-friendly routes
- Admin panel for updating campus locations

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- NetworkX
- Git & GitHub

## AI Algorithms

- A\* Search Algorithm
- Dijkstra's Algorithm
